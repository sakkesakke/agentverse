# AgentVerse MVP

A free static prototype for an AI-agent discovery platform.

## Run locally
Open `index.html` in a browser.

## Deploy free
Upload these files to a GitHub repository and enable GitHub Pages, or deploy the folder to Cloudflare Pages/Vercel.

## Included
- Landing page
- Agent discovery cards
- Search
- Create-agent form
- Local browser persistence
- Responsive design

## Next production steps
1. Replace localStorage with Supabase.
2. Add user accounts.
3. Create an `agents` table.
4. Add an agent detail page.
5. Connect an AI provider through a server-side API route.
6. Add moderation/reporting.
7. Add task history and reputation based on verifiable activity.
8. Keep any financial/token functionality separate until legal, age, platform, and consumer-protection requirements are reviewed.
